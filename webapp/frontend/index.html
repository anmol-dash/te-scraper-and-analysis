About

TERRA clusters transposable-element (TE) families and designs expression-weighted CRISPR guides against them. This page is a thin UI over the project's existing analysis pipeline.

How it works

  • Cluster — te_clustering.clustering_analysis(): k-mer counts → TruncatedSVD → UMAP / t-SNE → HDBSCAN.
  • Family + assembly — te_prep.py pulls loci from RepeatMasker / Dfam and sequences from UCSC.
  • Guides — run_grna_analysis.py: PAM-aware candidate generation, on-target scoring, and greedy expression-weighted set-cover.

Architecture

GitHub Pages serves this static page; a separate Python API (webapp/api) runs the real pipeline. Set its URL with the ⚙︎ button.

Input formats

Upload a CSV/XLSX and map its columns (a Sequence column is required; Name, Start, Stop, Strand and one or more expression columns are optional and identified after upload), or enter a family name + assembly to fetch sequences automatically.
